# adriana — versione pubblicata

Questo repository contiene **un solo file**: il numero dell'ultima versione
pubblicata del Planetario Natale 3D.

```json
{ "version": "0.2.0", "notes": "..." }
```

L'applicazione lo legge una volta al giorno e, se esiste una versione più
recente di quella in uso, lo dice. Non si aggiorna da sola.

## Perché è pubblico

Leggere da un repository privato richiede un token, e un token dentro
un'applicazione distribuita è estraibile da chiunque la riceva: un prezzo
assurdo per leggere un numero.

Qui non c'è nulla da proteggere — non l'applicazione, non il codice, non un
file da scaricare. Il progetto vive altrove e resta privato.
